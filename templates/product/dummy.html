Trailer Generator — Live Demo

Every run randomizes: title animation style, clip selection, color grade, zoom, speed, and transitions. This preview uses synthetic "clips" since no real footage is loaded here — swap in your Symfony assets paths (see note below) and everything else works unchanged.

Press play to generate a trailer.
Wiring into Symfony / Twig

1. Pass your data from the controller into Twig, generated with Faker:
{{ '{' }}{ movie: { title: faker.movieTitle, clips: assetPaths } {{ '}' }}

2. In the template, drop the config on the page before this script (or read it from data-attributes):
<script>window.TRAILER_CONFIG = {{ '{{' }} trailer_config|json_encode|raw {{ '}}' }};</script>

3. Replace CLIP_SOURCES below with real {{ '{{' }} asset('videos/clip1.mp4') {{ '}}' }} paths (5 of them). The engine randomly picks 2–3 per trailer, so with randomized filters/zoom/speed/transitions on top, five source clips already produce hundreds of distinct-feeling trailers — no need for a huge video library.
